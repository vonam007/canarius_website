## 🧭 About Canarius Tech

Canarius Tech is an early-stage AI startup founded in 2026. We are exploring how Claude and modern agent architectures can be used to build reliable software for real business workflows.

Our focus is not on generic chatbots. We are developing systems that combine language understanding, retrieval, structured reasoning, and controlled tool use to perform useful tasks while remaining observable and controllable.

---

## 🛠️ Active Prototypes Under Development

1. **AI Commerce Assistant (Prototype)**:
   - Conversational discovery, catalog retrieval, product ranking, and structured API responses.
2. **Customer Support Agent (In Development)**:
   - Policy knowledge retrieval, intent classification, tool calling, and human handoff gates.
3. **Knowledge & Workflow Agent (Research)**:
   - Internal RAG assistant with controlled API access and audit logging.

---

## 🔬 Development & Engineering Priorities

- **Reliable tool execution**: Strict schema validation and bounded tool execution.
- **Structured outputs**: Type-safe JSON responses for direct consumption by software applications.
- **Traceable reasoning**: Step-by-step visibility from user prompt to tool execution.
- **Human oversight**: Clear approval checkpoints for sensitive or uncertain actions.
